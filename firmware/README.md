# Classroom firmware

Use `pio run -d firmware -e yolo_uno` from the repository root for the physical classroom. The default build enables DHT20, light, PIR, ultrasonic distance, servo door, LCD, and independent lamp and RGB outputs. See the [system integration guide](../docs/SYSTEM_INTEGRATION.md) for the provisional pin map, electrical checks, broker setup, upload procedures, and native CoreIOT OTA lab builds.
